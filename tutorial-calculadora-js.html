Vamos construir uma calculadora em JavaScript!

Neste tutorial você vai montar, pedacinho por pedacinho, o código de uma calculadora que faz soma e subtração.

Você vai praticar três ideias importantes da programação:

  • Arrow functions — um jeito curto de escrever funções.
  • Switch statement — para escolher qual operação fazer.
  • Operador ternário — para decidir algo em uma linha só.

Em cada passo, clique nas peças certas para completar o código. No final, você vai copiar o código pronto e testar no MyCompiler.
